# le-mot-mystere
Projet Python : jeu du mot mystere
le mot mystere
Jeu developper en Python dans lequel le joueur doit deviner un mot de 5 lettres
Regles du jeu
  L'ordinateur choisit un mot au hasard.
  Le joueur dispose de 6 essais.
  Des indices sont affiches après chaque proposition.
Technologies utilisees
  Python
  Git et Github
